# =====================================================================================
# 황혼의 신탁 — 이야기 데이터 (대사 · 진행 단계 · 지역)
# 근거 문서: 저장소 루트의 STORY.md(스토리 바이블 v0.3). ID·플래그는 STORY.md 규칙을 그대로 쓴다.
# 게임을 켤 때마다 이 파일을 읽으므로, 대사만 고칠 땐 다시 컴파일하지 않아도 된다(게임만 다시 실행).
# 읽다가 틀린 줄이 있으면 콘솔에 "[이야기 데이터] 줄 N: ..."으로 알려 주고 그 줄만 건너뛴다.
#
# ---- 형식 ----
# '#'로 시작하는 줄은 주석이다. 줄 중간의 #은 주석이 아니라 대사의 일부다.
#
# name <화자ID> <표시 이름>          대화창 이름표. 표시 이름을 비우면 지문(이름표 없음).
# step <단계ID> [<지역ID>] [@대상,대상,...] <목표 문구>
#                                    진행 단계. 선언한 순서가 곧 진행 순서다(조건식의 STORY_STEP 크기 비교).
#                                    <지역ID>(LOC_로 시작): 목표가 있는 지역. 플레이어가 다른 지역에 있으면 목표 표시
#                                    (머리 위 마름모·발밑 화살표·미니맵·지도)가 지금 있는 지역의 이정표를 가리키고, 목표
#                                    문구 아래에 목적지가 뜨며, 이정표 선택지 중 그 지역으로 가는 것에 "◆ 목표"가 붙는다.
#                                    지역을 비우면 따지지 않는다(대상이 지금 지역에 하나도 없을 때만 이정표를 가리킴).
#                                    @대상: 머리 위에 금빛 마름모를 띄울 스토리 ID들(쉼표로 잇고 공백 없이).
#                                    "ID?조건"이면 그 조건이 참일 때만 표시한다(조건에도 공백 없이, 예: A&&!B).
#                                    목표 문구엔 {변수}를 쓸 수 있다.
# region <지역ID> <지역 이름> | <한마디>   지역에 들어설 때 뜨는 이름 배너와 헤르메스의 한마디.
# bark <화자ID> (조건) <대사>         그 인물이 곁(8칸 안)에 있을 때 45~75초마다 채팅창에 뜨는 혼잣말.
#
# == <대화ID>                         대화 블록 시작. 다음 == 까지가 이 블록이다.
#   on talk|pickup|trigger|kill|enter <대상ID>
#                                    대화가 저절로 열리는 계기(말 걸기/줍기/트리거 영역 진입/처치/지역 도착).
#                                    on 줄이 없으면 다른 대화의 GOTO로만 열린다.
#   if <조건>                         모두 참이어야 열린다(여러 줄 가능).
#   once                              한 번 본 뒤로는 열리지 않는다.
#   <화자ID>: <대사>                  PLAYER는 플레이어, narr는 지문. {변수}는 그 값으로 바뀐다.
#   choice [(조건)] <문구> -> <효과>; <효과>   선택지(숫자키로 고름). 조건이 거짓이면 보이지 않는다.
#   do <효과>; <효과>                 대화가 끝날 때 적용(선택지가 있으면 고른 선택지 효과보다 먼저).
#   or                                여기부터 다음 변형. 같은 대화를 다시 열면 변형을 차례로 돌려 가며 보여준다.
#
# 같은 계기·대상에 블록이 여럿이면, 조건이 맞는 것 중 이 파일에서 가장 먼저 나온 블록이 열린다.
# → 진행 단계별로 구체적인 블록을 위에, 평소 잡담을 아래에 둔다.
#
# 조건: A && B || C 는 (A && B) || C (괄호는 없음). 항은 변수 / !변수 / 변수 연산자 값 (== != >= <= > <).
#       STORY_STEP끼리는 step 선언 순서로, 정수끼리는 수로, true/false는 참거짓으로 비교한다.
#       설정한 적 없는 변수는 빈 값이다(거짓, 수로는 0).
# 효과: SET 변수 값 / ADD 변수 수 / STEP 단계ID / UNLOCK 지역ID / GOTO 대화ID(그 대화의 조건이 참일 때만 열림) /
#       TRAVEL 지역ID / XP 수 / HEAL / NOTICE 문구(채팅창 안내 — 문구에 ; 는 쓸 수 없음) /
#       EVENT BLESSING(수호신의 첫 축복) / EVENT SHAKE 초(화면 흔들림) / EVENT FLARE 스토리ID(흐려진 신이 잠깐 선명해짐)
#       대화가 열려 있는 동안 GOTO로 부른 대화는 지금 대화가 끝난 뒤에 차례로 열린다.
#
# ---- 변수 ----
# STORY.md 8장의 변수: PATRON, PATRON_TRUST(기본 50), HUMAN_FAITH(기본 50), ERIS_CLUE(0~5), FLAG_THREADLESS_REVEALED,
#   MQ02_DONE, PYTHIA_LOST 등. 분기 판정은 STORY.md 8장 변수를 기준으로 한다.
# 구현용 진행 기록(게임 진행을 기록하는 변수라 여기에만 정리한다 — STORY.md 8장은 분기·엔딩 판정 변수만 둔다):
#   STORY_STEP            지금 진행 단계(아래 step 목록)
#   MAP                   지금 있는 지역 ID(지역에 들어설 때 게임이 설정)
#   UNLOCK_<지역ID>       이정표로 갈 수 있는 지역(UNLOCK 효과로 열리고, 한 번 가 본 지역은 게임이 자동으로 true)
#   LAUREL                MQ_00 축제 준비로 모은 월계수 가지 수
#   CRACK_OPEN            신탁의 균열이 열렸는지(그림자 괴물이 나오고 순례객이 흩어짐)
#   PYTHON_SLAIN          그림자 퓌톤을 쓰러뜨렸는지
#   MQ01_SCHEDULE_SEEN    헤르메스에게 면접 일정표를 받았는지
#   MET_<신>              MQ_01에서 면담을 마친 신(ZEUS / POSEIDON / HADES / APHRODITE / HERMES)
#   INTERVIEW_COUNT       MQ_01에서 면담을 마친 신의 수
#   HERMES_GOSSIP_SEEN    헤르메스의 황금사과 가십(복선 F-03)을 들었는지
#   BLESSING_GRANTED      수호신의 첫 축복을 받았는지(EVENT BLESSING이 설정)
#   ATHENS_ARRIVED / DELPHI_RETURNED   지역에 처음 도착·다시 돌아왔을 때의 연출을 봤는지
#   HEARTH_GOD_NAMED      MQ_02에서 옛 화로의 신에게 이름을 불러 줬는지(SQ_ATHENS_02로 이어질 예정)
#
